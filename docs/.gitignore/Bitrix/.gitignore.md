# .gitignore (Bitrix)

> Профессиональный `.gitignore` для проектов на 1С-Битрикс.
> Стратегия: **не трекать Bitrix core**, трекать только исходники проекта (`/local/`, шаблоны, конфиги).

## Что исключается

| Категория | Пути / паттерны |
|-----------|----------------|
| Bitrix core и кеши | `/bitrix/`, `/bitrix/cache/`, `/bitrix/managed_cache/`, `/bitrix/modules/` |
| Загрузки пользователей | `/upload/` |
| Бекапы | `/bitrix/backup/`, `backup_*/` |
| Конфиги с секретами | `/bitrix/.settings.php`, `/local/.settings.php`, `.env` |
| Временные файлы | `/bitrix/tmp/`, `/bitrix/stack_cache/` |
| Зависимости | `node_modules/`, `vendor/` |
| Логи и профилировщик | `*.log`, `/local/logs/`, `/xhprof/` |
| Медиа и бинарники | `*.psd`, `*.ai`, `*.mov`, `*.mp4`, `*.zip`, `*.sql` и др. |

## Что трекается (явные разрешения)

| Что | Зачем |
|-----|-------|
| `/local/` и `/local/**` | Весь кастомный код лежит здесь |
| `/local/templates/` | Шаблоны сайта |
| `/bitrix/.settings.php.sample` | Шаблон конфига без секретов |

## Структурная политика

- Весь проектный код должен быть в `/local/` — это стандарт Битрикс D7.
- Компоненты: `/local/components/vendor/component/`
- Шаблоны: `/local/templates/my_site/`
- Если есть кастомный код внутри `/bitrix/` — переноси в `/local/`, либо явно разрешай через `!/bitrix/my_dir/`.

## Подключение на проекте

```bash
cp .gitignore/Bitrix/.gitignore /var/www/my-bitrix-project/.gitignore
cd /var/www/my-bitrix-project
git rm -r --cached .
git add .
git commit -m "Apply Bitrix .gitignore"
```
