# .gitignore (WordPress)

> Профессиональный `.gitignore` для WordPress-проектов.
> Стратегия: **не трекать WP core и плагины**, трекать только темы и исходники проекта.

## Что исключается

| Категория | Пути / паттерны |
|-----------|----------------|
| WordPress core | `/wp-admin/`, `/wp-includes/`, `/wp-*.php`, `/xmlrpc.php` |
| Загрузки и кеши | `/wp-content/uploads/`, `/wp-content/cache/`, `/wp-content/upgrade/` |
| Плагины | `/wp-content/plugins/` |
| Секреты | `wp-config.php`, `.env`, `.env.local` |
| Зависимости | `node_modules/`, `vendor/` |
| Логи | `*.log`, `wp-content/debug.log` |
| Медиа и бинарники | `*.psd`, `*.ai`, `*.mov`, `*.mp4`, `*.zip`, `*.sql` и др. |
| Хостинговые файлы | `_wpeprivate`, `.wpe-backup`, `.smushit-status` |

## Что трекается (явные разрешения)

| Что | Зачем |
|-----|-------|
| `/wp-content/themes/` | Темы — это и есть проект |
| `wp-config-sample.php` | Шаблон конфига без секретов |
| `.htaccess` | Конфигурация сервера |
| `robots.txt` | SEO-файл |

## Структурная политика

- `wp-config.php` не трекается — содержит credentials к БД. Шаблон `wp-config-sample.php` трекается.
- Плагины не трекаются — устанавливаются через `composer.json` или вручную при деплое.
- Must-use plugins (`/wp-content/mu-plugins/`) не трекаются по умолчанию — раскомментируй в файле, если нужно.
- Если нужно исключить build-артефакты конкретной темы — добавь явно: `/wp-content/themes/my-theme/dist/`

## Подключение на проекте

```bash
cp .gitignore/Wordpress/.gitignore /var/www/my-wp-project/.gitignore
cd /var/www/my-wp-project
git rm -r --cached .
git add .
git commit -m "Apply WordPress .gitignore"
```
